# Dyslexia and AI

This repository contains research papers and associated code related to accessibility and language models.

---

## 📁 Project Structure

All materials are organized in the following folders:

### 📂 AIED 2025
Contains the paper and code for:

**“Dyslexia and AI: Do Language Models Align with Dyslexic Style Guide Criteria?”**

Contents include:
- Research paper
- Experimental codebase
- Evaluation scripts and results

---

### 📂 AIED 2026
Contains the paper:

**“Feedback Dynamics in Agentic LLM-Based Text Accessibility”**

Contents include:
- Research paper
- Experimental codebase
- Evaluation scripts and results

---

## 📌 Overview

This repository explores how large language models interact with accessibility-focused writing guidelines, with a focus on:
- Dyslexia-friendly text generation
- Feedback-driven accessibility improvements
- Agentic LLM behavior in rewriting and optimization tasks
